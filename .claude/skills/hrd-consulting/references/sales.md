## 1. 営業プロセスの全体像

| 段階 | 目的 | アウトプット |
|---|---|---|
| 事前準備 | 顧客の事業・組織・人事課題の仮説を立てる | 顧客の調査メモ、仮説、ヒアリングシート |
| 初回商談 | 課題を深掘りし、関係者と意思決定プロセスを把握する | 商談記録、お礼メール |
| 提案 | 課題→解決策→効果→投資を示す | 提案書、見積 |
| 合意・受注 | 懸念を解消し、契約条件を決める | 修正提案、契約書 |
| 受注後 | 設計・実施・効果測定 → 継続提案 | CSに引き継ぐ（`customer-success.md`） |

**人材育成の商談で押さえる関係者**：人事・人材開発部門（窓口）、受講者の所属部門の責任者（研修の効果を求める人）、経営層（予算の承認者）、購買部門。窓口の人事担当者が社内で説明しやすい材料（経営課題とのつながり、効果測定の計画）を渡すことが受注の鍵になる。

**確認すべき項目（BANT＋α）**：Budget（予算）、Authority（決裁者）、Need（課題）、Timeline（実施時期）、加えて、比較している他社、過去の研修とその評価、成功の定義。

## 2. SPIN話法によるヒアリング設計

ニール・ラッカムが大型商談の研究をもとに体系化した質問の型。顧客自身に課題の深刻さと解決の価値を語ってもらうことが核心である。

| 質問の型 | 目的 | 研修営業での例 |
|---|---|---|
| S：状況質問 | 事実を把握する（事前に調べればわかることは聞かない） | 「新任管理職は年間何名くらい登用されますか」「現在の管理職研修の内容を教えてください」 |
| P：問題質問 | 不満・困りごとを引き出す | 「新任管理職の方が最もつまずいているのはどんな場面ですか」 |
| I：示唆質問 | 問題を放置したときの影響を広げる | 「その状態が続くと、部下の定着や業績にどう影響しそうですか」「現場の責任者の方はどう見ていますか」 |
| N：解決質問 | 解決したときの価値を顧客に語ってもらう | 「管理職の方が1on1で部下の育成を担えるようになると、どんな変化が期待できますか」 |

- 状況質問は最小限にする（多すぎると顧客の満足度が下がる）。事前の調査で補う
- 示唆質問が最も重要で、最も準備が必要。経営指標（離職率、採用費、売上、品質）と結びつける
- 解決策の説明は、解決質問で顧客がその価値を語った後にする

## 3. ヒアリングシート

商談の前に、**事前準備チェックリスト**（顧客のWebサイト・IR・採用ページ・ニュースの確認、業界の公的統計の最新値、同席者の役割、持参資料）を付けておくと使いやすい。

構成：
1. 商談の基本情報（日時、参加者と役割、商談の目的）
2. 事前の仮説（顧客の事業状況、想定される人材課題、出典つき）
3. SPINの質問リスト（各型3〜5問、優先順位つき）
4. 確認項目（BANT＋α）のチェック欄
5. 記入欄（顧客の発言の要点、顧客が使った言葉はそのまま書く）
   - 課題の原因を「研修で解決できる／一部解決できる／研修では解決できない（報酬・評価制度・配置など）」に仕分ける欄を設ける。研修で解決できない原因を正直に分けることが、後の信頼につながる
6. 次のアクション（誰が・何を・いつまでに）

## 4. トークスクリプト

- 構成：オープニング（お礼・目的と時間の確認・アジェンダの合意）→ 関係づくり → ヒアリング（SPIN）→ 要約と確認 → 情報提供（事例・考え方。売り込みではなく示唆として）→ 次のステップの合意 → クロージング
- 一言一句を読む台本ではなく、**分岐**（顧客がこう答えたら→次の質問）と**目的**（このパートで何を確認するか）を明記する
- 顧客が使った言葉を、要約や提案で繰り返し使う（「先ほど『プレイヤーから抜け出せない』とおっしゃった点ですが」）

## 5. 提案書

標準構成（10〜15枚程度）：
1. 表紙
2. エグゼクティブサマリー（1枚で：課題 → 解決策 → 期待効果 → 投資額）
3. 貴社の現状と課題の認識（ヒアリングで聞いた顧客の言葉を使う）
4. 課題の構造（原因の分析。研修で解決できる部分と、制度や上司の関与が必要な部分を分けて示す）
5. 目指す姿と目標（L1〜L4の指標）
6. 解決策の全体像（研修の前・当日・後の仕掛け、70:20:10）
7. プログラムの詳細（カリキュラムの概要、手法、時間）
8. 効果測定の計画
9. スケジュール
10. 体制・講師の紹介
11. 実績・事例（出典・掲載許可があるもののみ。数値を作らない）
12. 費用
13. 次のステップ

## 6. 提案メール・フォローメール

- **件名**：何のメールか一目でわかるように（例：「【ご提案】新任管理職向け1on1研修のご提案（〇〇株式会社様）」）
- **本文の構成**：お礼 → 商談の要点の確認（顧客の課題を顧客の言葉で）→ 提案の要点（3点以内）→ 添付資料 → 次のステップ（日程の候補を具体的に）→ 署名
- 300〜500字が目安。長くなる内容は添付資料に回す
- 商談当日〜翌営業日に送る
- **状況別に差し替え案を用意する**：商談の結果は事前にわからないため、主なパターンごとに下書きを用意する。例：(a) 次回の日程が決まった場合、(b) 日程が未定で候補日を提示する場合、(c) 来期予算での検討になった場合。また、ヒアリングで判明した主な原因に応じて、提案の要点を入れ替えられるようにしておく

## 7. よくある反論への対応

| 反論 | 背景にある懸念 | 対応の方向 |
|---|---|---|
| 「予算がない」 | 優先度が低い、または費用対効果が見えない | 課題が続いた場合の損失（示唆質問の内容）を確認し、段階的な導入や小規模の試行を提案する |
| 「研修は効果が出ない」 | 過去の失敗 | 過去の研修の何がうまくいかなかったかを聞き、行動変容の仕掛けと効果測定の計画を示す |
| 「内製でできる」 | 費用、自社に合うか | 内製化の支援（講師育成、ファシリテーターガイドの提供）も選択肢として示す |
| 「他社のほうが安い」 | 比較の基準が価格だけ | 比較の基準（成果、カスタマイズ、測定）を一緒に整理する |
| 「上に確認します」 | 決裁者が別にいる | 社内説明用の資料を提供し、決裁者への説明の場を提案する |
