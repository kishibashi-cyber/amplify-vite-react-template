# アウトプット別の構成テンプレート

ファイルの作成手順（pptx・xlsx・docxの技術的な作り方）は、各形式のスキルに従う。このファイルは「何を・どの順で載せるか」を定める。`assets/company/` に自社テンプレートがあれば、そちらを優先する。

## 目次
1. 研修企画書・提案書（スライド）
2. カリキュラム・研修進行表（Excel）
3. 受講者用テキスト・ワークシート・ファシリテーターガイド（Word／ドキュメント）
4. 評価基準表・事前／事後アンケート（Excel）
5. ヒアリングシート・トークスクリプト・提案メール
6. CS関連（成功計画・ヘルススコア・QBR）

---

## 1. 研修企画書・提案書（スライド）

- **研修企画書**（社内向け・人事部門が経営に説明する用）：表紙 → サマリー → 背景と課題 → 目的と目標（L1〜L4）→ 対象者と規模 → プログラムの全体像 → カリキュラムの概要 → 効果測定の計画 → スケジュール → 体制 → 予算 → リスクと対策
- **提案書**（顧客向け）：`sales.md` の「5. 提案書」の構成
- 1スライド1メッセージ。各スライドのタイトルは、名詞ではなく**主張を表す文**にする（「研修の目的」ではなく「1on1の定着で、新任管理職の部下の離職を防ぐ」）
- 図解を使う：課題の構造（ロジックツリー）、プログラムの流れ（研修の前・当日・後のタイムライン）、測定（L1〜L4の表）

## 2. カリキュラム・研修進行表（Excel）

**シート構成の例**：
1. `概要`：研修名、目的、対象、人数、日時、会場／形式、講師、学習目標（ABCD形式）
2. `カリキュラム`：日・モジュール・学習目標・主な内容・手法・時間（分）・対応する評価（L1〜L4）
3. `進行表`：開始・終了・所要時間（分）・パート・ねらい・内容・手法・教材・講師の動き・受講者の動き・備考
4. `準備物`：教材・備品・数量・担当・期限

**作り方の注意**：
- 開始・終了時刻と所要時間は数式で連動させる（終了＝開始＋所要時間、次の開始＝前の終了）
- 合計時間の行を設け、指定の研修時間と一致することを確認する
- 休憩・昼食も行として入れる
- ヘッダーの固定、列幅の調整、折り返し表示で、印刷して読める状態にする

## 3. 受講者用テキスト・ワークシート・ファシリテーターガイド

**受講者用テキスト**：表紙 → 研修の目的とゴール → 進め方（アジェンダ）→ 各章（ねらい・要点・図解・事例・演習の指示・まとめ）→ 職場での実践計画 → 参考資料

**ワークシート**：タイトル → 目的・所要時間・手順 → 記入欄（具体的な問い）→ 記入例（別ページまたは講師用）

**ファシリテーターガイド**：
- 冒頭：研修の目的、対象者の特徴、全体の流れ、準備物、会場レイアウト
- パートごと：時間／ねらい／進め方（トークの要点、問いかけ、板書）／演習の指示文（読み上げ用）／想定される反応と対応／時間調整の案（短縮・延長）
- 末尾：よくある質問への回答例、トラブル対応

## 4. 評価基準表・事前／事後アンケート（Excel）

**評価基準表（ルーブリック）**：列＝評価項目・対応する学習目標・評価者・時期・レベル1〜4（各段階の行動の記述）。`assessment.md` の作り方に従う。

**アンケート**：
- シート `設問一覧`：No.・時期（事前／直後／3か月後）・評価レベル（L1〜L3）・回答者（本人／上司）・設問文・回答形式（5段階／選択／自由記述）・選択肢・ねらい
- 事前と事後で比較する設問には同じIDを振り、比較できることを明示する
- 必要に応じて、フォームへ転記しやすいテキスト版も添える

## 5. ヒアリングシート・トークスクリプト・提案メール

`sales.md` の3・4・6節の構成に従う。ヒアリングシートは印刷して商談中に書き込めるよう、記入欄を広く取る。

## 6. CS関連

- **成功計画**：顧客の目的・成功の定義とKPI・マイルストーン・役割分担・リスク（1〜2枚のスライドまたは表）
- **ヘルススコア**（Excel）：顧客名・各指標・重み・点数・総合点・判定・次の対応・担当・期限。総合点と判定は数式で計算する
- **QBR資料**（スライド）：`customer-success.md` の4節の構成
